# Практическая работа №1 — система управления складом

## Что было сделано

Разработано Java-приложение для управления складами и каталогом товаров.

### Модель товаров

- Создан абстрактный базовый класс `Product` с общими характеристиками:
  - уникальный идентификатор;
  - название;
  - цена;
  - количество;
  - вес;
  - категория.
- Цена, количество и вес вынесены в отдельные классы-атрибуты `Price`, `Quantity`, `Weight`.
- В классах-атрибутах реализованы инкапсуляция и валидация значений.
- Созданы три иерархии товаров:
  - магические артефакты;
  - цифровые продукты;
  - роботы.
- Реализованы конкретные товары с собственными характеристиками и проверками данных.
- Добавлены операции изменения цены и остатка товара.
- Реализовано перемещение товара между складами.

### Клонирование и глубокое копирование

- В `Product` определён абстрактный метод `clone()`.
- В конкретных товарах реализованы копирующие конструкторы и ковариантные версии `clone()`.
- При клонировании создаются независимые объекты `Price`, `Quantity`, `Weight`.
- Клон получает новый уникальный идентификатор.
- Для `Warehouse` реализован копирующий конструктор с глубоким копированием всех товаров.

### Управление складами

- Создан класс `Warehouse` на основе `ArrayList<Product>`.
- Реализовано ограничение максимального количества товарных позиций.
- Добавлены операции:
  - добавление товара;
  - удаление по ID;
  - удаление по индексу;
  - поиск по ID;
  - поиск по категории;
  - поиск по цене;
  - перенос одного товара;
  - перенос всех товаров между складами;
  - глубокое копирование склада.
- Добавлены проверки заполненности склада и принадлежности товара конкретному складу.
- При неудачном переносе товара реализован откат операции.

### Итератор

- `Warehouse` реализует интерфейс `Iterable<Product>`.
- Для обхода товаров адаптирован стандартный итератор `ArrayList`.
- Склад поддерживает цикл `for-each`.
- Итератор используется при отображении товаров в графическом интерфейсе.

### Паттерн «Фабричный метод»

- Создан абстрактный класс `ProductFactory` с общим методом `createProduct(...)`.
- Для каждого конкретного товара реализована отдельная фабрика.
- Общие свойства товарной позиции передаются в фабричный метод.
- Специфическая конфигурация товара хранится в конкретной фабрике.
- Клиентский код может работать через общий тип `ProductFactory` и получать `Product`, не вызывая конструктор конкретного товара напрямую.

### Графический интерфейс

- Создан графический интерфейс на Java Swing.
- Реализована таблица товаров через собственную модель `ProductTableModel` на основе `AbstractTableModel`.
- Добавлен динамический диалог создания товара:
  - сначала выбирается категория;
  - затем конкретный тип;
  - форма перестраивается под характеристики выбранного товара;
  - товар создаётся через соответствующую фабрику.
- Реализовано управление несколькими складами.
- Через GUI доступны:
  - создание склада;
  - копирование склада;
  - перемещение всех товаров;
  - добавление и удаление товаров;
  - поиск;
  - изменение цены и количества;
  - перемещение товара;
  - просмотр полной информации о товаре.
- Для просмотра специфических характеристик используется полиморфный метод `getDetails()`.
- Добавлена обработка ошибок через диалоговые окна без аварийного завершения приложения.
